# Le Mans Autoworks Uganda

**Your car's favorite hangout spot.**

A modern, responsive automotive service website for **Le Mans Autoworks Uganda**, designed to showcase automotive repair services, connect customers with the workshop, and make service booking easier.

> Fix it. Tune it. Make it fly.

---

## About the Project

Le Mans Autoworks is an automotive repair and maintenance workshop located in Kampala, Uganda. This website serves as the workshop's digital presence, allowing customers to explore services, learn about the business, view workshop projects, and request service appointments.

The website combines a modern automotive aesthetic with a bold visual identity, interactive elements, and a responsive layout designed for both desktop and mobile users.

## Website Features

- **Modern homepage** – A bold automotive-themed landing page.
- **About Us** – Information about Le Mans Autoworks, its workshop, location, and approach to service.
- **Services catalogue** – Dedicated pages for individual automotive services.
- **Service booking** – A convenient way for customers to request vehicle servicing.
- **Our Work** – A showcase of workshop projects and automotive work.
- **Contact page** – Business contact information and location details.
- **Responsive design** – Adaptable layouts for desktop, tablet, and mobile devices.
- **Mobile navigation** – Mobile-friendly navigation experience.
- **Interactive UI elements** – Dropdown menus, buttons, animations, and visual transitions.
- **WhatsApp integration** – Direct access for customer enquiries.
- **Call-to-action sections** – Designed to encourage customers to book or contact the workshop.

## Running Locally

You can run the website locally without installing a framework or build tools.

### Option 1 — Open directly

Clone the repository:

```bash
git clone https://github.com/Kambere-44/le-mans-autoworks.git
```

Navigate to the project folder:

```bash
cd le-mans-autoworks
```

Open `index.html` in your browser.

### Option 2 — Run using a local server

If you have Python installed:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

This project is suitable for deployment as a static website on platforms such as:

- [Render](https://render.com/)
- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://www.netlify.com/)

### Render Deployment

1. Push the project to GitHub.
2. Log in to [Render](https://render.com/).
3. Select **New → Static Site**.
4. Connect the `le-mans-autoworks` repository.
5. Configure the deployment settings:

| Setting | Value |
|---|---|
| Repository | `Kambere-44/le-mans-autoworks` |
| Branch | `main` |
| Build Command | Leave blank |
| Publish Directory | `.` |

6. Click **Create Static Site**.

Render will deploy the website and provide a public URL.
